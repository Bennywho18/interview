02 / Core Pillars

三大技術支柱深度剖析

每一層技術並不是用來「淘汰」上一層，而是各自在特定資料形態、算力預算與可解釋性需求下擁有無可取代的定位。

機器學習

Classical Machine Learning
📊

透過數學統計與優化演算法，讓電腦從結構化或半結構化資料（如試算表、交易日誌、感測數值）中歸納決策邊界，分為監督式、非監督式與強化學習三大範式。

  • 手工特徵工程：仰賴領域專家挑選欄位與轉換特徵，模型邏輯透明、易受法規稽核。
  • 輕量高效：數千筆至百萬筆資料即可展現極高準確度，一般 CPU 就能秒級推論。
  • 代表應用：信用卡詐欺偵測、工廠預測性維護、顧客分群行銷、保險精算定價。
XGBoost LightGBM Random Forest SVM K-Means

深度學習

Deep Neural Networks
🧠

以多層堆疊的人工神經元與反向傳播（Backpropagation）為核心，從原始像素、音訊波形或訊號中「端對端」自動學習由淺入深的抽象表徵。

  • 空間與序列專精：CNN 稱霸影像網格辨識；RNN/LSTM 擅長時序記憶；Autoencoder 專攻降噪與異常偵測。
  • 算力與數據驅動：需要大量訓練樣本與 GPU / TPU 矩陣平行運算才能發揮威力。
  • 代表應用：醫療 MRI/X 光腫瘤判讀、自駕車環境感知、即時語音轉錄、推薦排序引擎。
CNN / ResNet RNN / LSTM ViT Diffusion Autoencoder

大型語言模型

Large Language Models
✨

建立於 Transformer 自注意力架構的超大規模基礎模型，歷經兆級 Token 預訓練、人類偏好對齊（RLHF）與推論期強化學習（Reasoning），實現跨領域認知與代理協作。

  • 從快答到慢思考：2025–2026 推理模型透過內部思維鏈（CoT）與測試期算力擴展，大幅突破數學與程式瓶頸。
  • 原生全模態：單一骨幹同時詞元化處理文字、程式碼、影像、音訊與即時影片。
  • 代表應用：對話助理、軟體工程師 AI 協作、企業 RAG 知識檢索、多步驟自主 Agent。
Transformer MoE RLHF / GRPO RAG Test-Time Compute
03 / Machine Learning Deep Dive

深入機器學習：四大範式、工作管線與泛化原理

機器學習的核心使命不是「記住過去的答案」，而是從有限樣本中提煉出能夠準確預測未知資料的泛化（Generalization）規律。以下從學習範式、端對端流程，到最關鍵的「偏差–變異權衡」與演算法光譜，逐層拆解機器學習本質。

PARADIGM 01

監督式學習 Supervised

提供成對的「輸入特徵 X 與標準答案標籤 Y」，讓模型學習兩者的映射函數 f(X) ≈ Y。分為預測連續數值的迴歸（如房價預測）與判別類別的分類（如垃圾郵件過濾）。

代表：線性迴歸、SVM、隨機森林、XGBoost
PARADIGM 02

非監督式學習 Unsupervised

資料完全沒有人工標籤，演算法必須自行發掘隱藏結構。核心應用包含將相似樣本歸類的分群（Clustering）、壓縮維度的降維（PCA）以及異常偵測。

代表：K-Means、DBSCAN、PCA、隔離森林
PARADIGM 03

半監督 / 自監督學習

現實世界標註資料昂貴且稀缺。透過結合少量標註資料與海量未標註資料（或像語言模型以「遮蔽/預測下個字」自動創造偽標籤），大幅降低人工標註門檻。

代表：Pseudo-Labeling、現代預訓練基礎模型
PARADIGM 04

強化學習 Reinforcement

代理者（Agent）在環境中不斷嘗試動作（Action），依據回饋獎勵（Reward）學習使長期累積報酬最大化的最佳策略（Policy），廣泛用於博弈、機器人控制與 LLM 對齊。

代表：Q-Learning、PPO、GRPO、AlphaGo

🔄 標準機器學習專案五階段管線（End-to-End ML Pipeline）

業界經驗：資料清理與特徵工程往往佔據 60%–80% 時間，卻決定了最終模型上限
1

資料收集與清理

處理缺失值、異常極端值、重複紀錄與類別不平衡（如詐欺交易僅佔 0.1%），確保「垃圾不進、模型不偏」。

2

特徵工程與縮放

將原始欄位轉化為高價值特徵（如消費頻率、比率指標），並進行 One-Hot 編碼與標準化（StandardScaler）。

3

嚴謹資料切分

切分為訓練集（Train）、驗證集（Validation）與獨立測試集（Test），嚴防資料洩漏（Data Leakage）。

4

模型訓練與調參

最小化損失函數（MSE / Cross-Entropy），透過 K 折交叉驗證挑選最佳演算法與正則化超參數。

5

評估部署與監控

檢視 Precision/Recall、F1、AUC 等業務指標，上線後持續追蹤資料漂移（Data Drift）並定期重訓。

04 / Deep Learning Deep Dive

深入深度學習：神經網路如何「學習」、梯度下降與架構演進

深度學習的核心魔法在於「用數學微積分自動調整數百萬至數千億個權重」。從單一神經元的線性加權與非線性激活，到反向傳播與梯度下降優化，最終演化出專精不同資料形態的五大深度神經架構。

深度學習核心直覺

為什麼「深度」與「非線性」帶來質變？

單一人工神經元只做一件簡單的事：將輸入向量乘上權重加上偏差 z = w·x + b，再通過一個非線性激活函數 a = σ(z)。當數百層神經元層層串聯，第一層學會辨識像素邊緣、中層組合成眼睛或車輪、深層就能直接辨識整張人臉或醫療病灶——完全無需人工撰寫特徵規則。

2012 年 AlexNet 結合 GPU 平行矩陣運算與 ReLU 引爆革命；2015 年 ResNet 憑藉殘差跳躍連接（Skip Connections）與批次正規化（BatchNorm），徹底解鎖百層以上深層網路的訓練極限。

⚙️ 深度神經網路訓練四步驟閉環（Training Loop）

每次輸入一個 Mini-Batch 資料，網路就會重複執行這四個步驟數萬至數百萬次
1

前向傳播 Forward Pass

資料逐層經過矩陣乘法與非線性激活函數，從輸入端一路計算至輸出端，產生預測機率分佈 ŷ。

2

損失計算 Loss Function

以損失函數（如交叉熵 Cross-Entropy 或均方誤差 MSE）量化預測值 ŷ 與真實答案 y 之間的差距分數。

3

反向傳播 Backpropagation

運用微積分鏈鎖律（Chain Rule）由輸出層往回推算誤差對每一層權重的偏導數（梯度 ∂L/∂w）。

4

梯度下降更新 Optimizer

優化器（如 SGD、AdamW）依學習率 η 沿負梯度方向微調所有權重，讓下一次預測更接近正確答案。

05 / Large Language Models Deep Dive

深入大型語言模型：訓練生命週期、機率生成與推理時代

大型語言模型本質上是一個「在超高維語意空間預測下一個詞元」的機率引擎，卻在規模突破臨界點、歷經指令微調與強化學習對齊後，湧現出驚人的世界知識、寫作編程與多步驟邏輯推理能力。

2024–2026 前沿範式轉移

三大核心躍遷：擴展定律、原生全模態與「慢思考」推理

  • Scaling Laws 的三次演進：從 2020 年預訓練冪律（C ≈ 6ND）、2022 年 Chinchilla 算力最優配比（每參數約 20 Tokens），演進至 2025–2026 年的測試期算力擴展（Test-Time Compute）——讓模型在回答前多花推論算力思考，換取媲美參數倍增的解題突破。
  • 原生全模態（Any-to-Any）：拋棄早期外掛轉接器，現代 Omni 模型將文字、影像、音訊與程式碼直接詞元化進入同一條 Transformer 骨幹同步理解與生成。
  • System-2 推理模型崛起：透過結果與過程獎勵（ORM / PRM）結合強化學習（如 GRPO / PPO 變體），讓模型學會拆解難題、自我檢查並主動修正推論錯誤。

🏗️ 現代 LLM 四階段誕生管線與算力佔比結構

從原始網路文字到安全推理助理的完整蛻變
總訓練算力資源分佈（高度前置於預訓練階段）：
■ 預訓練 Pre-training (~95%–99%)：萬卡 GPU 跑數月，注入世界知識 ■ 指令微調 SFT (~1%–3%)：學會對話格式 ■ 對齊與推理 RL (~1%–2%)：安全對齊與深度思考
1

預訓練 Pre-training

以自監督「預測下一個詞元」讀遍數十兆網頁、書籍與程式碼，產出知識淵博但尚未學會對話禮儀的 Base Model。

2

監督微調 SFT / LoRA

使用數萬至數十萬組高品質「提問–理想回答」示範對話進行精修，教會模型聽懂系統指令、角色扮演與結構化輸出。

3

偏好對齊 RLHF / DPO

透過人類偏好排序（RLHF + 獎勵模型 PPO，或免獎勵模型的直接偏好優化 DPO），大幅降低有害輸出與胡亂編造。

4

推理強化 GRPO / RL

針對數學、程式等可驗證任務，讓模型生成多條思維鏈並以群組相對獎勵（GRPO）自我演進，激發反思與驗算能力。

比較維度 機器學習 (ML) 深度學習 (DL) 大型語言模型 (LLM)
核心定義 從結構化與半結構化資料學習統計規律，進行數值預測或分類。 透過多層類神經網路處理複雜非結構化資料並自動提取高維特徵。 基於 Transformer 的超大規模深度學習模型，專精語言理解、生成與推理。
資料規模依賴 中小型資料集（數千至百萬筆）即可達到優異成效。 高度依賴大量標註或未標註資料（數十萬至數億樣本）。 需要 PB 級網路文本、書籍、程式碼與高品質合成資料（數十兆詞元）。
特徵工程 人工主導：需由領域專家設計欄位與衍生指標，可解釋性極高。 自動學習：端對端由神經網路自動發掘空間或時序特徵。 自動且具語境：無須手工特徵，直接透過提示詞或少量範例適應新任務。
硬體與成本 標準 CPU 即可快速訓練與毫秒級推論，部署成本最低。 訓練需 GPU / TPU 加速；邊緣推論常需量化壓縮。 預訓練需數千至萬張高階 GPU 叢集；實務多採 API 呼叫或微調開源權重。
代表演算法 線性/邏輯迴歸、決策樹、隨機森林、SVM、XGBoost、K-Means。 MLP、CNN（ResNet）、RNN/LSTM、Autoencoder、Diffusion。 Decoder-Only（GPT / Llama / DeepSeek）、Encoder（BERT）、MoE 推理模型。
殺手級應用 金融風控與詐欺偵測、需求預測、設備預測性維護、客群細分。 醫療影像輔助診斷、自駕車視覺感知、即時語音辨識、個人化推薦。 AI 對話助理、程式碼生成與重構、長文件摘要翻譯、企業 RAG 與自主 Agent。
